# Real YouTube AArch64 playback evidence — 2026-08-26

Source watch URL: `https://youtu.be/GwtNiL9eEYk`

No signed Google Video URL, cookie, IP address, or authorization token is stored
in this file.

## Root cause

- The current URL resolves successfully with yt-dlp.
- A request from old FFmpeg without a bounded Range returns HTTP 403.
- The same URL with a bounded Range returns HTTP 206 and identifies H.264.
- A direct `http-header-fields` option is not sufficient because the stock mpv
  HTTP layer replaces the Range during open/seek.
- The loopback range bridge is therefore the compatibility boundary.
- Android-VR format 298 is H.264 1280x720 at 60 fps, but without a GVS PO token
  its high-offset ranges are not consistently authorized.
- Android format 18 was sampled at offsets 0, 1, 8, 16, 32, and 64 MB; all
  samples returned HTTP 206. It is the safe default.

## Interpretation

This proves that the real YouTube media was resolved, transported across 34
bounded CDN requests, and decoded by the target AArch64 libmpv/FFmpeg libraries
for 5.533 measured media seconds with both H.264 and AAC selected. It does not
prove device DRM/KMS output, Cedrus hardware decode, or physical speaker output;
those require an RG40XX V device test.
